## 🎯 About the Module / អំពីម៉ូឌុល

**`universe_huokaingthara_story_storie_video`** showcases story videos, short narratives, mystery/supernatural stories, and comedic story episodes produced under **UNIVERSE HUOKAING THARA Group**. It provides a clean bilingual browsing experience with instant filtering, search, and a story player preview modal.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **🔎 Live Search & Genre Filtering:** Filter story videos by genre (*Drama & Romance, Mystery & Ghost, Comedy Story*) or search by title, theme, or credit in real time.
* **🎬 Story Player & Synopsis Modal:** Open a preview player displaying story title, genre, runtime/resolution metadata, and full synopsis notes.
* **🌐 Dual Language Switcher (Khmer / English):** Instant toggle supporting Khmer-only, English-only, or bilingual display modes.
* **🌙 Dark / Light Cyberpunk Theme:** Styled with the signature **UNIVERSE HUOKAING THARA** holographic scanline aesthetic and adaptive theme switching.

## 🛠️ Tech Stack & Architecture / បច្ចេកវិទ្យាប្រើប្រាស់

- **Frontend Core:** Semantic HTML5, CSS3 (CSS Grid, Flexbox, Custom Properties), Vanilla JavaScript (ES6+)
- **Typography:** Google Fonts (`Kantumruy Pro` for Khmer script, `Poppins` for English UI)
- **Icons:** FontAwesome v6.4.0
- **UI/UX Design:** Cyberpunk Holographic Dark/Light Theme with Scanline Overlay
